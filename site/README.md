# Madim — лендинг стоматологии

Статический одностраничный лендинг для стоматологии Madim (Одесса, ул. Пироговская, 13/3).
Полностью независим от `/backend` (виджет виртуальной примерки) — отдельная папка, отдельный деплой.

## Стек

Чистые HTML/CSS/JS без сборки и зависимостей (кроме шрифтов Google Fonts). Это сознательный выбор
для одностраничного брошюр-сайта: минимальный вес, максимальная скорость, без build-шага.

## Структура

- `index.html` — разметка и контент
- `styles.css` — дизайн-система (токены в `:root`), вёрстка, адаптив
- `script.js` — скролл-reveal, мобильное меню, sticky call-bar, шапка при скролле
- `favicon.svg` — иконка вкладки

## Запуск локально

Любой статический сервер, например:

```bash
cd site
python3 -m http.server 8080
# или
npx serve .
```

## Контент и факты

Реальные данные клиники (адрес, часы работы, телефон, перечень услуг, описание) — из открытого
источника, указанного заказчиком. Цены и имена врачей не публиковались нигде, поэтому в лендинге
их нет — вместо этого везде CTA «уточняйте по телефону». Если появятся: цены логично добавить в
`.services-list` (доп. `<span class="service-price">`), врачей — отдельным блоком между `#uslugi`
и `#podhod`.

## Что стоит заменить в первую очередь

- Абстрактная line-art графика (SVG-дуги в hero и в контактах) — заглушка на случай, если позже
  появятся реальные фото клиники/кабинета. Никаких стоковых фото не использовано намеренно.
- Ссылка на карту в разделе «Контакты» ведёт на Google Maps по поисковому запросу адреса
  (геокодинг на стороне Google) — при наличии точных координат можно заменить на прямую ссылку
  с pin.
