Website Speed and Core Web Vitals: What to Check and How to Speed Up in 2026

A slow website loses customers before they even see it. Here are Google's metrics and simple steps that improve them.

The three Core Web Vitals

  • LCP (loading speed of the main content): good is under 2.5 s
  • INP (responsiveness to user actions): good is under 200 ms
  • CLS (layout stability, no "jumping"): good is under 0.1

These are the thresholds Google considers "good". You can see them in Search Console (Core Web Vitals) and PageSpeed Insights.

How to check

Enter your URL in PageSpeed Insights and look at the mobile version separately: it is usually the weaker one. Pay attention to real-user data when available, not just the overall score.

8 ways to speed up your site

  • Compress images and use modern formats (WebP/AVIF)
  • Lazy-load images below the first screen (loading="lazy")
  • Set image dimensions so the layout does not jump
  • Load only the fonts and weights you need
  • Remove or defer unnecessary scripts (chats, widgets, tracking pixels)
  • Minify CSS and JavaScript
  • Enable caching and a CDN
  • Choose fast hosting and a fast platform

Why it matters for SEO and sales

Core Web Vitals are one of Google's page experience signals, but the direct effect matters more: the longer a page takes to load, the more people leave. For an online store every second of delay means lost orders. It is part of technical SEO worth checking right away.

FAQ

What is a good website speed?

Google considers LCP under 2.5 s, INP under 200 ms and CLS under 0.1 to be good.

Does site speed affect Google rankings?

Yes, as one of the page experience signals, and through user behaviour: slow pages are abandoned more often.

What slows a website down most?

Heavy images, extra scripts, fonts and weak hosting.
