Встановлення на сайт

Один рядок коду — кнопка "Приміряти" з'явиться на сторінках товарів

1
Автоматична кнопка
Скрипт сам знайде місце і вставить кнопку після кнопки "Купити"
<script
  src="https://lumion.onrender.com/widget.js"
  data-brand="..."
  data-api-url="https://lumion.onrender.com"
  data-lang="uk"
></script>
2
Власна кнопка (рекомендовано)
Додай атрибути до своєї кнопки — повний контроль над виглядом
<button data-lumion="try-on"
  data-image="URL фото товару"
  data-id="product-id"
  data-name="Назва товару"
  data-url="URL сторінки">
  Приміряти
</button>
3
UTM-мітки (автоматично)
Всі закази через примірку отримають ці параметри
utm_source=tryon utm_medium=widget utm_campaign=... utm_content={product_id}
4
Horoshop / OpenCart
Вставити в поле "Скрипти перед </body>" в налаштуваннях сайту
Налаштування → Структура сайту → Скрипти → Скрипти перед тегом </body>
